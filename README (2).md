## 🚀 Featured ML project

### AI-powered technical log analyzer

Built a learning project using generated sample LTE/5G logs to explore failure patterns at the device level.

- Parsed log events and engineered per-device features, including failure rates and retransmission counts.
- Used TF-IDF to classify log events and combined NLP-derived counts with numerical features.
- Trained a model to classify likely root causes and surfaced anomaly signals for investigation.
- Evaluated predictions with precision, recall, F1 score, and class-level results.

**Stack:** Python · Pandas · scikit-learn · TF-IDF · NLP · Feature engineering
