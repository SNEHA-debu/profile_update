## 🚀 Featured ML Project

### AI-Powered Technical Log Analyzer

Built a learning project using generated sample LTE/5G logs to explore failure patterns at the device level.

- Parsed log events and engineered device-level features, including failure rates and retransmission counts
- Applied TF-IDF to classify log events and combined NLP-derived term counts with numerical features
- Trained a model to predict likely root causes and highlight anomaly signals for investigation
- Evaluated model performance using precision, recall, F1-score, and class-level analysis

**Stack:** Python · Pandas · scikit-learn · TF-IDF · NLP · Feature Engineering
